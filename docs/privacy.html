Privacy Policy

Yomitan with Bunpro · Last updated: 14 November 2026

Yomitan with Bunpro is an unofficial community fork of Yomitan. It is not affiliated with yomidevs, the official Yomitan project, or Bunpro Inc.

What this extension stores locally

Settings, dictionaries you import, and other extension data are stored in your browser’s local extension storage. That data stays on your device unless a feature below sends it elsewhere.

Bunpro integration (optional)

Only when you enable Bunpro and save an API key:

  • Your Bunpro API key is stored locally in the extension.
  • The key is sent only to https://api.bunpro.jp (Bunpro’s frontend API), using Bunpro’s documented API-token authentication.
  • Lookups may send Japanese headwords and/or JMdict sequence ids to Bunpro so the extension can find matching vocabulary and show review status.
  • Add / remove review actions send the relevant Bunpro vocabulary identifiers to the same API.
  • The API key is never sent to the extension author, analytics services, or any host other than Bunpro.

If Bunpro is disabled, or no API key is saved, the extension does not contact Bunpro. You can clear the saved key at any time in Settings → Bunpro.

Other optional network features (inherited from Yomitan)

Same as upstream Yomitan, and only when you turn them on:

  • Audio — may send term/reading/language to the audio source you configured.
  • Anki — may send note data to AnkiConnect on your machine (or the host you configure).
  • Parsing / mecab-style helpers — may send text to a local or configured parsing service.
  • Clipboard / native messaging — only if you grant those permissions.

Analytics and tracking

This fork does not include analytics, advertising, crash-reporting SDKs, or account systems of its own. It does not sell personal data.

Permissions

Broad site access is used so the dictionary popup can run on pages you read. Bunpro traffic uses that same network capability and is limited in practice to api.bunpro.jp when the integration is enabled.
